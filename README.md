## The error

> ERROR E7: I washed the dishes. The plates are clean. The smell is still here. It was never the dishes.

102 characters, one line. A dishwasher reports the one fault it cannot wash
away: the smell was never on the dishes — it is the drain/filter, and the
machine did its job perfectly on the wrong problem.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with no trailing
newline, and prints it. Fully deterministic.
